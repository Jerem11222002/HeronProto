Legend & Key Information

PK = Primary Key (Unique identifier)
FK = Foreign Key (Reference to another table)
UK = Unique Key (Must be unique)
||--o{ = One-to-Many relationship (one record relates to zero or more)
}o--|| = Many-to-One relationship

Core Entities

USER - Central entity with authentication, profile, interests, and social connections
POST - User-generated content with media, engagement metrics, and tagging
COMMENT - Comments/replies on posts with nested reply structure
EVENT - Organization events with registrations and ticketing
EVENT_REGISTRATION - Registration records for events
CONVERSATION & MESSAGE - Direct messaging system with attachments and reactions
NOTIFICATION - User activity notifications
INTEREST - Interest/tag catalog
