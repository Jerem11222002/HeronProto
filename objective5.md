5. To design and develop a web-based application tailored to the Center for Culture and the Arts, incorporating the following modules: User Module and Administrator Module. 
The development of Heron Fusion followed the Agile/WDLC methodology, transitioning the requirements identified from the 61 usable respondents into a functional prototype . The platform was built using React, Node.js, and MongoDB to provide a specialized hub for the University of Makati CCA community.



Following the visual documentation style of the reference study, each of the 22 sequences implemented in the prototype is presented below 



1. Sign-Up Page
As defined in Sequence 1, this feature allows users to easily create an account to join the community and showcase their art. The interface includes a registration form equipped with real-time input validation to ensure data integrity during the onboarding process.

2. Interest Page
This module, corresponding to Sequence 2, enables users to choose multiple interests, such as Music or Digital Arts, to tailor their feed contents
. Users have the flexibility to select from predefined categories, enter custom interests, or skip the process entirely

3. Account Profile Setup
Following Sequence 3, this interface allows users to finish setting up their account by uploading a profile picture, adding a bio, and changing their display name. This ensures that artists can establish their identity before interacting with the wider community.

4. Sign-In Page
As specified in Sequence 4, the Sign-In page facilitates secure account access. It includes a toggle to switch between Admin and User views, as well as a shortcut to the sign-up flow for new visitors. 


5. Home Page
The Home Page serves as the primary entry point. It loads featured artworks and announcements to provide immediate value to visitors and guides them toward the sign-up or login options.

6. User Profile
This feature follows Sequence 6, providing tools for users to manage their profile information and personalize their experience
. The interface utilizes a modal for editing personal details efficiently

7. Artwork Upload
Per Sequence 7, this module enables users to share their artwork with the community
. It incorporates drag-and-drop functionality and fields for filling in specific artwork details


8. Art Feed
As described in Sequence 8, the Art Feed displays dynamic recommendations based on user interests.
. The interface includes interactive elements for users to like, comment on, and share artworks discovered through the hybrid filtering engine.

9. Feedback System
Figure X. Critique and Feedback Section.
Following Sequence 9, this system allows users to provide constructive feedback on artworks. It provides an accessible feedback form for each post with specific criteria to help fellow artists improve their skills.


10. Events Feed
Per Sequence 10, this interface centralizes available events to enhance user skills and community engagement. Users can view active events and access specific details for each activity.


11. Event Registration Details Page
As defined in Sequence 11, this page allows users to check the status of their event registrations
. It displays active registration details to keep the user informed of upcoming CCA participation


12. Admin Dashboard
Following Sequence 12, this interface allows administrators to stay updated with the latest activities.
. It provides an overview of active events, analytics, and recent system interactions

13. Admin Events
As specified in Sequence 13, this module empowers admins to create engaging events for the community. It includes tools to Create, Edit, or Delete event details and scheduling.


14. Admin Analytics
Per Sequence 14, this feature allows admins to monitor the performance data of the application.
. It includes the capability to Export CSV files of engagement data for further coordination and reporting


15. Participants Page
Following Sequence 15, administrators can view the registration details of event participants
. This interface allows admins to evaluate, accept, or reject user registration requests.


16. Admin User Accounts Page
Exclusive to the Super Administrator as defined in Sequence 16, this page allows for the modification of admin credentials and control of administrative privileges.


17. User Monitoring Page
As described in Sequence 17, this page enables admins to maintain a safe environment by viewing user activities.
. Admins can use this interface to approve or reject uploaded artworks.


18. Settings Page
Per Sequence 18, this page allows both users and admins to change system settings.
. Users can modify the system’s appearance (Theme) and update their account password.


19. Chat Functionality
. It provides access to a chat feature with notifications for new messages to facilitate real-time communication between artists.


20. Featured Artists Section
As defined in Sequence 20, this module recognizes outstanding artworks to motivate community engagement.
. The system automatically notifies artists when they are selected to be featured


21. Notification Dropdown
Per Sequence 21, users can stay updated with account activities through a navbar-based list.
. This interface allows users to view system notifications related to likes, shares, and event updates.
